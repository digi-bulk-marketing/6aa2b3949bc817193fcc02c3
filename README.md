# Sender Pro Lite

Sender Pro Lite by AiBotCRM.

## Installation

### Windows
1. Download the latest **`.exe`** installer from the [Releases page](https://github.com/digi-bulk-marketing/6aa2b3949bc817193fcc02c3/releases/latest).
2. Run the installer and follow the prompts.
3. Launch **Sender Pro Lite** from the Start menu.

## Updates

Download the newest installer from the [Releases page](https://github.com/digi-bulk-marketing/6aa2b3949bc817193fcc02c3/releases/latest) and reinstall.
